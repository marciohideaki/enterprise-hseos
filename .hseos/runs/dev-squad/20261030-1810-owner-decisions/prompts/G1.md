## Defeito (achado na campanha MRTR com o Claude Code 2.1.316 real)
`capabilityToolDescriptors` (`tools/lib/governed-execution/operational-runtime.js:~405`) publica para todas as ferramentas `environment.*` e `memory.*` o `inputSchema: { type: 'object', additionalProperties: true }`, sem nenhuma propriedade.

Com isso, o cliente não conhece os tipos. O modelo enviou `scope` como string JSON e `ttl_seconds` como string, e o servidor recusou com `AGENT_MEMORY_INVALID` ("input does not match schema v1"). A validação real é programática: `memorySchema`, `lspSchema` e `dapSchema` em `tools/lib/governed-execution/contract-registry.js`.

## Entregas
1. Cada contrato de capability passa a ter um **JSON Schema 2020-12 publicável** da entrada. Ele descreve campos, tipos, obrigatórios, enums e limites, e fica coerente com o validador programático. Defina o schema junto do contrato em `contract-registry.js` (por exemplo, `input_json_schema`). O validador em código continua sendo a fonte da verdade: o JSON Schema serve para o cliente e **não** substitui a validação.
   - `memory.write`, `memory.retrieve` e `memory.delete`: derive os campos de `assertEntryInputFields`, `normalizeEntry` e dos checks do `packages/agent-memory`. Por exemplo: `scope.project_id` string; `ttl_seconds` integer com os limites reais; `classification` enum. Campos proibidos via MCP (`origin`, `trust`, `created_at`) não entram, e use `additionalProperties: false` se o validador já recusa campo extra.
   - `environment.lsp.*`, `environment.dap.run`, `environment.computer.*` e `environment.browser.*`: derive de `lspSchema`, `dapSchema` e dos schemas existentes.
2. `capabilityToolDescriptors` publica esse schema no `inputSchema`. Se algum contrato não tiver schema, falhe na carga ou no teste; não volte ao schema aberto em silêncio.
3. **Teste de coerência**, o ponto central da task. Para cada contrato:
   - (a) o JSON Schema compila (ajv 2020);
   - (b) um conjunto de entradas válidas passa no JSON Schema **e** no validador;
   - (c) entradas inválidas por tipo (string no lugar de objeto ou de inteiro) são recusadas pelos dois;
   - (d) o caso da campanha: `scope` como string e `ttl_seconds` como string falham no JSON Schema.
4. O `tools/list` moderno do project-state, com `memory` configurado, expõe o schema com propriedades. Escreva o teste em `test/test-mcp-environment-host.js` ou num arquivo novo em `test/` registrado na suíte.
5. Docs: uma nota em `docs/v4-migration.md`, e no runbook `docs/evolution/runbooks/activation.md`, na parte de memória via MCP.
