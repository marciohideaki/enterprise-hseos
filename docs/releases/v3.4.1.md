## Rollback

Reinstall the checksum-verified v3.4.0 GitHub asset. This returns the runtime
to the prior pending status without deleting intake decisions or drift evidence.

```bash
rollback_version=3.4.0
rollback_dir="$(mktemp -d)"
gh release download "v${rollback_version}" \
  --repo marciohideaki/enterprise-hseos \
  --dir "${rollback_dir}"
(cd "${rollback_dir}" && sha256sum -c SHA256SUMS)
npm install --global "${rollback_dir}/hseos-${rollback_version}.tgz"
hseos --version
```
