## Install and rollback

Verify SHA256SUMS, then install the exact asset into a project-owned prefix:

```bash
sha256sum -c SHA256SUMS
npm install --prefix ./hseos-candidate ./hseos-4.0.0-ai-provider.6.tgz
./hseos-candidate/node_modules/.bin/hseos --version
```

Rollback removes only that isolated prefix and reinstalls the checksum-verified
`.5` asset. The published immutable `.5`, `latest` stable v3.4.2, global runtime,
human bindings, account profiles and app data are preserved.
