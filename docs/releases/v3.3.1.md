# HSEOS v3.3.1 Release Evidence

## Classification and authorization

- **Risk:** Low. This patch changes only executable selection in the advisory
  managed-governance session hook.
- **Breaking changes:** None.
- **Repository-owner acceptance:** correction, versioning, merge and publication
  were explicitly authorized in the active delivery session on 2026-09-01.
- **Promotion posture:** GitHub prerelease; `managed-enforced` and non-loopback
  control-plane exposure remain unavailable.
- **Change record:** [PR #142](https://github.com/marciohideaki/enterprise-hseos/pull/142)
  and ADR-0032.

## Correction

The session-start hook previously preferred an in-repository source CLI whenever
its entry file existed. A clean source checkout without installed dependencies
therefore emitted a false advisory even when the verified global HSEOS CLI was
available and functional. The hook now proves that the source CLI starts before
selecting it and otherwise falls back to the global installation.

The check remains advisory and bounded. Local governance remains authoritative,
and the hook still starts neither PostgreSQL nor the control-plane sidecar.

## Verification

- A regression fixture provides a broken source CLI and a working global CLI;
  the hook resolves the global command and reports a silent equivalent result.
- The exact live v3.3.0 PostgreSQL scenario reports 277 current artifacts and
  equivalent Constitution digests through CLI and MCP.
- The full enforced quality gate and protected-branch CI must pass before tag
  publication.
- The GitHub release pipeline verifies the package, builds an immutable tarball
  and SBOM, checks their digests and smoke-installs the produced artifact.

## Rollback

Reinstall the checksum-verified v3.3.0 GitHub asset. This only restores the
previous hook executable-selection behavior; it does not change managed data or
repository-owned governance.

```bash
rollback_version=3.3.0
rollback_dir="$(mktemp -d)"
gh release download "v${rollback_version}" \
  --repo marciohideaki/enterprise-hseos \
  --dir "${rollback_dir}"
(cd "${rollback_dir}" && sha256sum -c SHA256SUMS)
npm install --global "${rollback_dir}/hseos-${rollback_version}.tgz"
hseos --version
```

Use `sudo` only for an intentionally system-managed, non-writable global npm
prefix. User-managed Node installations must use their owning user.
