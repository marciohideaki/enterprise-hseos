## Corrected staging finding

An adapter and the portable compiler share `.agents/skills` while owning
different entries. Prefix-based cleanup removed a compiler-owned skill whose
name matched the adapter launcher namespace. Cleanup now derives the protected
set from `.agents/manifest.yaml`, removes only adapter-owned stale launchers, and
stops safely if an existing manifest cannot establish ownership.
