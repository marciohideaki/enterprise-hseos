# HSEOS v3.3.0 Release Evidence

## Classification and authorization

- **Risk:** Medium. The release adds backward-compatible CLI, MCP, hook and
  structured-result contracts without changing portable authority or database
  schema.
- **Breaking changes:** None.
- **Repository-owner acceptance:** implementation, versioning, merge and
  publication were explicitly authorized in the active delivery session on
  2026-09-01.
- **Promotion posture:** GitHub prerelease; `managed-enforced` and non-loopback
  control-plane exposure remain unavailable.
- **Change record:** [PR #141](https://github.com/marciohideaki/enterprise-hseos/pull/141)
  and ADR-0032.

## Capability

The optional managed-shadow client now provides a session preflight that
validates the project binding and repository identity, securely normalizes the
local Constitution, reads the active catalog through the existing loopback query
port and compares both identities and digests. CLI and native session-hook
execution atomically record the latest private evidence. MCP execution remains
stateless and read-only.

Every result is advisory and declares local governance authoritative. Supported
native `SessionStart` adapters run the check automatically; other adapters use
the documented CLI fallback. PostgreSQL and the sidecar are never started by the
hook.

## Verification and rollout

- Strict contract, CLI, MCP, hook, compiler, security and package-surface tests
  cover equivalence, drift, invalid local identity, malformed remote projection,
  outage, invalid UTF-8 and linked evidence paths.
- The full enforced quality gate passes with zero failures.
- Staging must run setup and the sidecar against an operator-supplied PostgreSQL
  database, prove `equivalent` through CLI and MCP, and inspect the console before
  release publication.
- After installing the GitHub asset, monitor session-hook completion and
  `remote_unavailable`/`drift_detected` results for at least 30 minutes.

## Rollback

Stop the optional sidecar and reinstall the checksum-verified v3.2.2 GitHub
asset. Local Markdown governance remains authoritative throughout rollback; do
not reverse additive database migrations or delete audit history.

```bash
rollback_version=3.2.2
rollback_dir="$(mktemp -d)"
gh release download "v${rollback_version}" \
  --repo marciohideaki/enterprise-hseos \
  --dir "${rollback_dir}"
(cd "${rollback_dir}" && sha256sum -c SHA256SUMS)
npm install --global "${rollback_dir}/hseos-${rollback_version}.tgz"
hseos --version
```

Use `sudo` only for an intentionally system-managed, non-writable global npm
prefix. User-managed Node installations must use their owning user.
