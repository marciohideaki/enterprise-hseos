  plane introduced in v3.2.0; this patch changes only fresh-install source
  materialization and its documentation.
- **Breaking changes:** None.
- **Repository-owner acceptance:** correction, publication and installation were
  explicitly authorized in the active delivery session on 2026-09-01.
- **Promotion posture:** GitHub prerelease only; managed enforcement and
  non-loopback exposure remain unavailable.
- **Change record:** [PR #140](https://github.com/marciohideaki/enterprise-hseos/pull/140).

## Root cause and correction

The importer correctly requires the canonical `.hseos/workflows` governance
source, but a fresh package installation previously materialized only the
runtime's module workflows and `.enterprise` overlay. v3.2.2 also scaffolds the
portable governance workflow registry and preserves an existing target tree.
Repository identity remains project-owned and is never copied from the package.

## Verification

- Installer smoke proves first-copy, idempotent preservation and self-target
  behavior for the governance workflow registry.
- A disposable consumer installed from the corrected package reaches managed
  setup `ready` against PostgreSQL with all 276 artifacts unchanged.
- Lint and the complete governed suite pass.
- CI builds an immutable tarball and CycloneDX SBOM covered by `SHA256SUMS`.

## Rollback

Stop the optional sidecar and reinstall v3.1.1 if managed setup must be removed.
Do not overwrite or delete v3.2.0 or v3.2.1; both remain immutable release
evidence. Keep local repository governance authoritative and retain additive
database history.

```bash
rollback_version=3.1.1
rollback_dir="$(mktemp -d)"
gh release download "v${rollback_version}" \
  --repo marciohideaki/enterprise-hseos \
  --dir "${rollback_dir}"
(cd "${rollback_dir}" && sha256sum -c SHA256SUMS)
npm install --global "${rollback_dir}/hseos-${rollback_version}.tgz"
hseos --version
```

Use `sudo` only for an intentionally system-managed, non-writable global npm
prefix. User-managed Node installations must use their owning user.
