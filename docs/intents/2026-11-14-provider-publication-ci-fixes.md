# Close the three provider publication CI failures

The final source CI rejected a stale generated CLI manifest, finalizer tests
without an explicit temporary directory on hosted CI, and the F14 rehearsal's
old source-content confirmation hash. This task repairs only those three gates.

The CLI manifest is regenerated by `npm run compile:cli`. Publisher tests now
create and remove their own temporary root, restore the inherited environment,
and retain a negative proving that the production finalizer still rejects a
missing TMPDIR before any network or publication operation.

The existing F14 producer ran in offline fixture mode against a newly created
synthetic temporary SQLite database: 42 runs, no protocol issues, no live model
calls and no canonical/human memory source or promotion. The registered real
attempt, protocol, plan, prices, guards and assertions are unchanged. The result
measures fixture plumbing, not provider usefulness or deployed consumption.
The current product-content confirmation hash is recomputed by the canonical
producer; it is not substituted manually. The Git head in that fixture is the
informative pre-commit parent; its product-content hashes bind the regenerated
working-tree bytes that this commit records.

Both the previous rehearsal and the exact regenerated producer bytes are archived
outside the checkout. JSON presentation is normalized with Prettier; a separate
check confirms every parsed object remains identical. Raw request JSONL bytes
are retained. No formatter exclusion, budget, source or integrity gate is relaxed.

Definition of done: CLI manifest check, publisher tests with TMPDIR absent,
unchanged F14 positive/negative suite against the fresh rehearsal, enforced code
gates, independent incremental review and all five required remote contexts on
the resulting PR head. SDK archives and runtime drivers are not rebuilt/changed.
