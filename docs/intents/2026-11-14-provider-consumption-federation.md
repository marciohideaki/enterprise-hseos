in one reference app, plus an isolated installable candidate that carries those
federated references. App PR29 and backend PR104 preserve immutable local normal-
app evidence and exact original SDK versions/digests. They do not establish a
second real consumer, public native deployment, stable/support or production use.

This task advances only owner pins, their compiled mirror and the prerelease
metadata needed to distribute the changed registry. It reuses the existing
compiler, required full-federation source CI, release controller, asset verifier
and clean consumer. The published `.5`, SDK archives, ECP6.2 and native drivers
remain unchanged. No new inference, premium call, SDK build or global activation
is authorized by this source update.

Done requires all eight fragments with no deferred source, one typed adoption
edge for this capability, exact two installed-artifact mappings, unchanged
publication/contract guards, independent review and the five protected source
contexts. The sealed candidate then needs independent byte review and actual
published-asset cold installation before immutable closeout. F14 fixture evidence
is regenerated only if the existing package-version confirmation requires it;
no runtime/provider qualification is expanded.

The separate reference-app bootstrap has priority whenever its CI frontier opens.
