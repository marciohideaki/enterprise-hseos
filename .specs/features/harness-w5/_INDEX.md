Glossário: authority = nível de autoridade de uma fonte de contexto (directive, operator, data);
proveniência = origem, digest, hora e cadeia de transformações; perfil de isolamento = conjunto
fixo de rede, seccomp e limites escolhido pelo controlador (P0 sem rede, P1 loopback, P2 loopback
com egresso mediado); toolchain pin = binário externo fixado por versão, SHA-256 e licença;
canal de artefatos = diretório gravável verificado pelo controlador, único caminho para saída
maior que o teto de stdout.
